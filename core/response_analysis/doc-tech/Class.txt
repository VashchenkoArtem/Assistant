# New about classes

## @staticmethod

- це вбудований декоратор, який перетворює метод класу на статичну функцію
- по суті є структурно відокремленою функцією для зручності використання

## private functions in python "_func_name"

- "_" перед назвам функції у Python є угодним правилом (конвенцією), яке вказує на те, 
що функція призначена для внутрішнього використання в межах цього модуля чи класу
