# sqlalchemy

## Types (from sqlalchemy)
(Float, Integer, String)

- класи для визначення структри данних таблиці 

## DeclarativeBase

- клас наслідник який компонує і зберігає всі данні про створенні таблиці, через нього SQLAlchemy розуміє які таблиці збирати

```
class Base(DeclarativeBase):
    pass
```

- перевизначення базового класу без додаткових налаштувань

## Mapped

- клас для вказання типізації для ORM

## mapped_column

- функція для розширеного налаштування стовбця, надаючи базові інструменти для цього (primary_key, nullable, default...)
