# typing

- вбудований модуль для розширення можливостей анотації

## Optional

- Значення може бути None (необов'язковий)

## Sequence

- упорядкована послідовність (з достпом до індексів)

## Iterable

- є можливим для перебору (for)

## Literal

## Конструкція TYPE_CHECKING
if TYPE_CHECKING:
    from sentence_transformers import SentenceTransformer

- дозволяє підвантажувати важкі модулі тільки при неоьбхідності анотації (викорситовувати з !__future__!)
