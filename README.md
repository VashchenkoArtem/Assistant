# Голосовий асистент

Поліна — настільний голосовий і текстовий асистент для Windows. Вона розпізнає українськомовні команди, керує встановленими програмами та файлами, працює з Провідником і відповідає голосом.

## Можливості

- керування встановленими Windows-програмами;
- відкриття файлів і папок, закриття програм і папок у Провіднику;
- керування вкладками та вікнами Провідника;
- текстовий чат із асистентом через графічний інтерфейс;
- голосове розпізнавання з мікрофона через `uk-UA`;
- озвучення голосових відповідей;
- інтерактивні підтвердження, вибір зі списку та скасування дій.

## Встановлення

1. Відкрийте проєкт у терміналі.

1. Створіть і активуйте віртуальне середовище:

```powershell
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
```

Якщо PowerShell забороняє запуск скрипта активації, виконайте в поточній сесії:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

1. Встановіть залежності:

```powershell
python -m pip install -r requirements.txt
```

1. Застосуйте міграції Django:

```powershell
python manage.py migrate
```

## Запуск

### Графічний інтерфейс

GUI та бекенд запускаються окремо в двох терміналах.

1. Термінал 1 — Django-бекенд асистента:

```powershell
python manage.py runserver 127.0.0.1:8765
```

1. Термінал 2 — графічний інтерфейс:

```powershell
  python -m gui
```

Команди з GUI надсилаються до бекенду асинхронно. Під час виконання попередньої команди інтерфейс продовжує працювати, а нові команди ставляться в чергу. Звичайний нерозпізнаний текст не перериває роботу програми.

Архітектура GUI розділена на модулі:

- `gui/main_window.py` — координатор головного вікна та UI-поведінка;
- `gui/workers.py` — асинхронні задачі для HTTP-бекенду й мікрофона;
- `gui/styles.py` — загальний Qt stylesheet;
- `gui/widgets/title_bar.py` — верхня панель із локальними стилями;
- `gui/widgets/sidebar.py` — ліва панель із локальними стилями;
- `gui/widgets/search_bar.py` — поле введення команди й кнопка мікрофона;
- `gui/widgets/chat_panel.py` — область історії повідомлень;
- `gui/widgets/composer.py` — поле введення та кнопки керування;
- `gui/widgets/input.py` — багаторядкове поле введення;
- `gui/widgets/chat_widgets.py` — картки повідомлень чату.

### Голосовий режим без GUI

```powershell
python manage.py run_assistant
```

## Використання GUI

1. У нижньому полі введіть українську команду.
1. Натисніть кнопку зі стрілкою, або натисніть Enter.
1. Для нового рядка натисніть Shift+Enter.
1. Натисніть кнопку мікрофона або використайте Ctrl+M.
1. Дочекайтесь розпізнавання фрази й перегляньте результат у чаті.
1. Після ввімкнення мікрофона асистент продовжує чекати наступні голосові команди.
1. Повторно натисніть кнопку мікрофона або Ctrl+M, щоб вимкнути прослуховування.

Текст, введений у рядку над чатом, надсилається після натискання Enter. Кнопка `Ctrl + M` запускає голосове введення.

## Приклади команд

```text
Привіт
Відкрий Steam
Закрий Telegram
Відкрий Провідник
Відкрий папку Завантаження
Відкрий файл звіт.docx
Відкрий папку C:\Users\user\Documents
Закрий папку Завантаження
Закрий усі папки
Закрий Провідник
Покажи відкриті папки
Закрий папку 1
Покажи відкриті вікна
Закрий вікно 2
Закрий всі вікна
Назад
Вперед
Відкрий налаштування
Скасувати
```

Якщо програма або папка знайдена неоднозначно, асистент покаже варіанти. Вкажіть номер, наприклад:

```text
Варіант 2
Я обираю номер два
```

`Покажи відкриті вікна` виводить список вікон Провідника з їхніми вкладками. Після цього назвіть номер одного вікна або скажіть `закрити всі`. Команда `Закрий Провідник` і надалі одразу закриває всі вікна.

Для підтвердження введіть `так`; для відмови — `ні` або `скасувати`.

## Команди паузи

У голосовому режимі доступні:

- `зупини` або `стоп` — зупинити асистента;
- `продовж` або `продовжуй` — відновити роботу.

```

Перевірити синтаксис основних модулів:

```

## Налаштування

Основні налаштування Django розташовані в [Assistant/settings.py](Assistant/settings.py).

База даних SQLite за замовчуванням: `db.sqlite3`.

База створюється через міграції та не міститься в репозиторії під час чистої установки. До виконання програмних команд спочатку запустіть `python manage.py migrate`.

## Усунення проблем

### GUI не запускається

- переконайтесь, що активовано `venv`;
- перевірте встановлення PyQt6: `python -m pip show PyQt6`;
- перевстановіть залежності: `python -m pip install -r requirements.txt`.

### Мікрофон не працює

- перевірте, чи Python має доступ до пристрою запису Windows;
- переконайтесь, що в Windows увімкнено дозвіл на доступ до мікрофона;
- перевірте встановлення PyAudio.

### Програму не знайдено

- перезапустіть Django-бекенд, щоб повторно синхронізувати список програм у базі даних;
- введіть точну назву ярлика або виконуваного файлу;
- якщо використовується голосове розпізнавання, уточніть назву повільніше.

### Не працює розпізнавання або озвучення

- перевірте підключення до мережі;
- переконайтеся, що доступні служби Google Speech Recognition і Edge TTS;
- перевірте, що програвач і звуковий пристрій Windows налаштовані коректно.
