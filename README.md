# Поліна — голосовий асистент

Поліна приймає текстові й голосові команди українською мовою, керує програмами та файлами й може відповідати голосом.

## Встановлення

Потрібен Python 3.12. У PowerShell з каталогу проєкту виконайте:

```powershell
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python manage.py migrate
```

## Запуск

Графічний інтерфейс:

```powershell
python -m gui
```

Голосовий режим у терміналі:

```powershell
python manage.py run_assistant
```

## Користування

- **Текстова команда:** введіть її в полі чату й натисніть Enter. Для нового рядка натисніть Shift+Enter.
- **Голосова команда:** натисніть кнопку мікрофона або Ctrl+M. Повторне натискання зупиняє прослуховування.
- **Аудіопристрої:** відкрийте налаштування в бічній панелі, виберіть мікрофон і вихідний пристрій, відрегулюйте гучність та натисніть «Зберегти».
- **Моделі ШІ:** відкрийте «Персоналізацію», щоб налаштувати провайдер і API-ключ.
- **Запит до ШІ:** у текстовому чаті починайте повідомлення з `/ai`, наприклад `/ai що таке REST API`. Без цього префікса повідомлення обробляється як звичайна команда асистента.
- **Уточнення:** коли асистент показує варіанти, введіть їхній номер. Для підтвердження дії відповідайте «так» або «ні», для скасування — «скасувати».

## Приклади команд

| Команда | Дія |
| --- | --- |
| `Відкрий Steam` | Відкрити програму |
| `Закрий Telegram` | Закрити програму |
| `Відкрий папку Завантаження` | Відкрити папку |
| `Знайди файл звіт.docx` | Знайти файл |
| `Покажи відкриті папки` | Показати вікна Провідника |
| `Пауза` / `Продовж` | Призупинити або відновити обробку команд |
| `Зупини` | Завершити роботу асистента |
