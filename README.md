# Голосовий асистент

Поліна — настільний голосовий і текстовий асистент для Windows. Вона розпізнає українськомовні команди, керує встановленими програмами та файлами, працює з Провідником і відповідає голосом.

## Можливості

- керування встановленими Windows-програмами;
- відкриття та закриття файлів і папок;
- пошук файлу за назвою в папках користувача та відкриття його папки;
- керування вкладками та вікнами Провідника;
- текстовий чат із асистентом через графічний інтерфейс;
- відповіді LLM у текстовому чаті за ключовими словами-тригерами;
- голосове розпізнавання з мікрофона через `uk-UA`;
- озвучення голосових відповідей;
- інтерактивні підтвердження, вибір зі списку та скасування дій.

## Структура проєкту

- `gui/app.py` запускає графічний інтерфейс;
- `gui/main_window.py` містить основне вікно та його поведінку;
- `gui/__main__.py` запускає GUI через `python -m gui`;
- `gui/icon_loader.py` спільно завантажує іконки для вікна й карток чату;
- `gui/assets/icons/` містить SVG-іконки, згруповані за призначенням (`window/`, `chat/`, `controls/`, `navigation/`, `status/`, `branding/`);
- `core/` містить логіку асистента та аналіз відповідей;
- `utils/` містить допоміжні модулі.

## Встановлення

1. Відкрийте проєкт у терміналі.

1. Створіть і активуйте віртуальне середовище:

```powershell
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
```

Якщо PowerShell забороняє запуск скрипта активації, виконайте в поточній сесії:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1
```

1. Встановіть залежності:

```powershell
python -m pip install -r requirements.txt
```

1. Застосуйте міграції Django:

```powershell
python manage.py migrate
```

## Запуск

### Необов'язкове підключення LLM

Використання LLM необов'язкове. У «Персоналізації» можна додавати будь-яку
кількість ключів, змінювати порядок провайдерів/моделей та додавати власні
OpenAI-сумісні або Anthropic Messages API. Google Gemini і Groq доступні як
вбудовані варіанти.

Маршрутизатор відкладає ключ після HTTP 429 на 90 секунд; 401/403 позначає
ключ недійсним до перезапуску або зміни налаштувань. При мережевій помилці,
таймауті чи 5xx робить один повтор, а потім відкладає провайдера на 45 секунд.
Після завершення паузи варіант знову доступний. Failover можна вимкнути у
вікні персоналізації.

```powershell
$env:GROQ_API_KEY = "ключ-groq"
$env:GROQ_API_KEY_2 = "додатковий-ключ-groq"
$env:GEMINI_API_KEY = "ключ-gemini"
```

Також підтримуються нумеровані змінні `GROQ_API_KEY_2`, `GEMINI_API_KEY_2` і
наступні ключі. Для сумісності `LLM_API_KEY` залишається псевдонімом Groq.
Змінні середовища можна використовувати поряд із ключами, доданими у вікні.
Модель також можна перевизначити через `LLM_MODEL` для Groq або `GEMINI_MODEL`
для Gemini.
Налаштування моделей та порядку зберігаються у `.llm_preferences.json`, а ключі
— окремо у `.llm_credentials.json`. Файл ключів ігнорується Git, але не
шифрується: захищайте доступ до облікового запису Windows і не надсилайте цей
файл.

У чаті введіть запит із префіксом `/ai`, наприклад: `/ai що таке REST API`.
Відповідь LLM з'явиться лише текстом у чаті.
Без API-ключів чат пояснить, як налаштувати LLM, а локальні команди
продовжать працювати.

### Графічний інтерфейс

Запустіть графічний інтерфейс:

```powershell
python -m gui
```

Ініціалізація асистента виконується у фоновому потоці. Під час виконання
попередньої команди інтерфейс продовжує працювати, а нові команди ставляться
в чергу. Звичайний нерозпізнаний текст не перериває роботу програми.

Архітектура GUI розділена на модулі:

- `gui/main_window.py` — координатор головного вікна та UI-поведінка;
- `gui/workers.py` — асинхронні задачі ініціалізації, команд і мікрофона;
- `gui/styles.py` — загальний Qt stylesheet;
- `gui/widgets/title_bar.py` — верхня панель із локальними стилями;
- `gui/widgets/sidebar.py` — ліва панель із локальними стилями;
- `gui/widgets/search_bar.py` — поле введення команди й кнопка мікрофона;
- `gui/widgets/chat_panel.py` — область історії повідомлень;
- `gui/widgets/composer.py` — поле введення та кнопки керування;
- `gui/widgets/input.py` — багаторядкове поле введення;
- `gui/widgets/chat_widgets.py` — картки повідомлень чату.

### Голосовий режим без GUI

```powershell
python manage.py run_assistant
```

## Використання GUI

1. У нижньому полі введіть українську команду.
1. Натисніть кнопку зі стрілкою, або натисніть Enter.
1. Для нового рядка натисніть Shift+Enter.
1. Натисніть кнопку мікрофона або використайте Ctrl+M.
1. Дочекайтесь розпізнавання фрази й перегляньте результат у чаті.
1. Після ввімкнення мікрофона асистент продовжує чекати наступні голосові команди.
1. Повторно натисніть кнопку мікрофона або Ctrl+M, щоб вимкнути прослуховування.

Кнопки в рядку пошуку над чатом надсилають текст після натискання Enter. Кнопка `Ctrl + M` запускає голосове введення.
Під час першого семантичного аналізу завантаження моделі позначається анімованою крапкою.

## Приклади команд

```text
Привіт
Відкрий Steam
Закрий Telegram
Відкрий Провідник
Відкрий папку Завантаження
Відкрий файл звіт.docx
Знайди файл звіт.docx
Відкрий папку C:\Users\user\Documents
Закрий папку Завантаження
Закрий усі папки
Закрий Провідник
Покажи відкриті папки
Закрий папку 1
Покажи відкриті вікна
Закрий вікно 2
Закрий всі вікна
Назад
Вперед
Відкрий налаштування
Скасувати
```

Якщо програма або папка знайдена неоднозначно, асистент покаже варіанти. Вкажіть номер, наприклад:

```text
Варіант 2
Я обираю номер два
```

`Покажи відкриті вікна` виводить список вікон Провідника з їхніми вкладками. Після цього назвіть номер одного вікна або скажіть `закрити всі`. Команда `Закрий Провідник` і надалі одразу закриває всі вікна.

Для підтвердження введіть `так`; для відмови — `ні` або `скасувати`.
Під час тривалого пошуку файлів введіть `скасувати`, щоб перервати пошук.
Під час нечіткого пошуку для закриття асистент розглядає лише запущені програми.

## Команди паузи

У голосовому режимі доступні:

- `зупини` або `стоп` — завершити роботу асистента;
- `пауза` — тимчасово призупинити обробку звичайних команд;
- `продовж` або `віднови` — відновити роботу.

## Налаштування

Основні налаштування Django розташовані в [Assistant/settings.py](Assistant/settings.py).

База даних SQLite за замовчуванням: `db.sqlite3`.

База створюється через міграції та не міститься в репозиторії під час чистої установки. До виконання програмних команд спочатку запустіть `python manage.py migrate`.

## Усунення проблем

### GUI не запускається

- переконайтесь, що активовано `venv`;
- перевірте встановлення PyQt6: `python -m pip show PyQt6`;
- перевстановіть залежності: `python -m pip install -r requirements.txt`.

### Мікрофон не працює

- перевірте, чи Python має доступ до пристрою запису Windows;
- переконайтесь, що в Windows увімкнено дозвіл на доступ до мікрофона;
- перевірте встановлення PyAudio.

### Програму не знайдено

- перезапустіть Django-бекенд, щоб повторно синхронізувати список програм у базі даних;
- введіть точну назву ярлика або виконуваного файлу;
- якщо використовується голосове розпізнавання, уточніть назву повільніше.

### Не працює розпізнавання або озвучення

- перевірте підключення до мережі;
- переконайтеся, що доступні служби Google Speech Recognition і Edge TTS;
- перевірте, що програвач і звуковий пристрій Windows налаштовані коректно.
